# Surface brief: /notes/ (лента заметок)

Scope: новая страница `/notes/`, пин `notes.md` в дереве, блок «Заметки» на главной, фиды `/rss.xml` и `/notes.xml`. Visitor mode: Read.

Audience and job: читатель статей заходит посмотреть, чем автор живёт между большими текстами. Читает подряд сверху вниз. Может скинуть одну заметку в телеграм по якорю.

Content: заметка от одного предложения до 3–4 абзацев, markdown, иногда ссылки, код, диаграмма. Лента от 0 до сотен записей, одна страница, без пагинации. Несколько заметок в день разводятся временем.

Authoring: файл на заметку в `src/content/notes/ГГГГ-ММ-ДД-ЧЧММ.md`, frontmatter `date` (с временем) и `draft`. Заголовка нет.

States: 0 опубликованных заметок → пин в дереве скрыт, страница /notes/ собирается с «Пока ничего нет.» без мета-строки (адрес стабильный для фидов и ссылок); черновики скрыты; переход по якорю подсвечивает запись подложкой на пару секунд.

Untouched: дерево статей, `/blog/`, фид статей не смешивается с заметками, стиль ссылок, тема, шрифт.

Anti-goals: карточки, теги, реакции, комментарии, счётчики, обрезка «читать дальше», аватар/подпись у записи, пагинация.

Open decision, resolved: время показываем, 24-часовое `ЧЧ:ММ`.

## Direction contract

THESIS: лента как git log: записи новыми сверху, у каждой только метка времени и текст. Отказ от карточного твиттер-ряда с аватарами и реакциями.

OWN-WORLD: тот же мир «Открытый проект в IDE»: JetBrains Mono, бумага/ночь, Monster Green только на ссылках и подсветке якоря. Запись = мета-строка Control-кеглем цветом Ink Muted (дата · время, она же якорь-ссылка) + текст Body. Между записями волосяная линия Paper Rule/Night Rule. Ни подложек, ни рамок у записей; подложка Paper Code/Night Code только на записи, на которую пришли по якорю, и гаснет.

STORY: читатель видит, что автор пишет прямо сейчас, читает 3–10 записей, уходит по ссылке в статью или кидает якорь другу.

FIRST VIEWPORT: как у страницы статьи: мета `дата последней · notes.md`, h1 «Заметки», волосяная линия, сразу первая запись. На десктопе ширина колонки статьи, на мобиле одна колонка. Главное действие: читать; вторичное: кликнуть время, чтобы получить якорь.

FORM: местное расширение установленного мира, без round-концептов; путь code-led, генерации изображений нет.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
