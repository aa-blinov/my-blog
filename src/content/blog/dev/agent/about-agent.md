Девять статей про устройство cast, моего кодового агента: от трёх строк цикла до тестов, которые стоят денег. Каждая часть разбирает одну границу вокруг модели: инструменты, контекст, роли, режим планирования, субагенты, память, демон, оценки.

Читать по порядку. Каждая часть опирается на предыдущую, а последняя собирает всё в одну картину.
