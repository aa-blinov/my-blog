29 июня 2021 года GitHub [показал Copilot](https://github.blog/news-insights/product-news/introducing-github-copilot-ai-pair-programmer/): «ИИ-напарник», который дописывает строку или целую функцию прямо в редакторе. Модель называлась Codex и была сделана OpenAI специально под код. У GitHub в тот момент было всё, что нужно для победы: самый большой в мире архив исходников, десятки миллионов разработчиков, деньги Microsoft и эксклюзивная лицензия Microsoft на GPT-3. Никто не мог начать раньше, и никто не начал.

Пять лет спустя в опросе JetBrains с мая по июль 2026 года, [больше 15 тысяч разработчиков](https://dev.to/jamilxt/claude-code-overtakes-github-copilot-what-jetbrains-survey-of-15000-developers-says-about-ai-3nhc), Claude Code используют 39%, Copilot 21%, Codex 16%, Cursor 12%. Год назад у Copilot было 29%, у Claude Code в январе 18%. Cursor к ноябрю 2025-го [перевалил за миллиард](https://en.wikipedia.org/wiki/Cursor_%28company%29) годовой выручки, а в августе 2026-го его купила SpaceX за 60 миллиардов. Claude Code за три месяца, с ноября 2025-го по февраль 2026-го, [вырос с миллиарда до двух с половиной](https://venturebeat.com/technology/anthropic-says-it-hit-a-30-billion-revenue-run-rate-after-crazy-80x-growth). У Copilot [4,7 миллиона платных подписок](https://axis-intelligence.com/github-copilot-statistics/) на январь 2026-го. Выручку Microsoft не раскрывает, аналитики по числу подписок и тарифам оценивают её в 0,9–1,1 миллиарда в год. Больше всех пользователей, и уже не первый по деньгам.

Мне интересно, как это могло произойти. У меня три ответа, и все три про одно.

Первый: продукт оказался моделью, а модель была чужая. Copilot с 2021 года был витриной OpenAI. Когда в марте 2023-го OpenAI [выключила модели Codex](https://benchlm.ai/blog/posts/openai-codex-deprecation) с тремя днями предупреждения, потому что новые GPT-3.5 стали писать код лучше специализированной модели, GitHub переехал на модели общего назначения от того же OpenAI: OpenAI рекомендовала GPT-3.5 Turbo, а [к ноябрю 2023-го](https://en.wikipedia.org/wiki/GitHub_Copilot) чат в Copilot работал на GPT-4. Выбор моделей в Copilot [появился только 29 октября 2024 года](https://github.blog/news-insights/product-news/bringing-developer-choice-to-copilot/), когда Claude 3.5 Sonnet уже четыре месяца был лучшей моделью для кода и [его уже можно было выбрать в Cursor](https://forum.cursor.com/t/resolved-the-model-claude-3-5-sonnet-does-not-work-with-your-current-plan-or-api-key/6461). Три года GitHub продавал качество, которое не контролировал, и когда оно кончилось у поставщика, кончилось и у него.

Кто победил? Два из трёх победителей делают модель сами. Claude Code это [терминальный агент Anthropic](https://www.anthropic.com/news/claude-3-7-sonnet), превью 24 февраля 2025 года. Codex это [такой же агент OpenAI](https://en.wikipedia.org/wiki/Codex_CLI), 16 апреля того же года, под тем же именем, что у мёртвой модели 2023-го. Третий, Cursor, модели не делает и не привязан ни к одной: он форкнул VS Code и меняет модели под задачу. GitHub оказался посередине: не хозяин модели и не свободен от неё.

Второй ответ: изменилась форма, и первая форма стала якорем. Copilot это серый текст после курсора. Так его узнали, так он продаётся, по десять долларов в месяц. Агент работает иначе: читает репозиторий, запускает тесты, правит десять файлов и возвращается с результатом. Ему не нужно поле ввода в редакторе, ему нужен терминал и права. Anthropic и OpenAI пришли в терминал, потому что им нечего было терять. Cursor забрал редактор целиком, потому что дописывать плагин к чужому редактору для агента мало. GitHub добавил [agent mode в феврале 2025-го](https://en.wikipedia.org/wiki/GitHub_Copilot) и облачного агента в мае, через три месяца и через полгода после того, как Cursor показал, как это выглядит. Каждая новая форма у него появлялась как вкладка внутри старой.

Третий ответ: организация. Платформа на сто с лишним миллионов разработчиков не может выкатывать инструмент, который ломается. Стартап с восемью миллионами на счету может. Cursor [основали четверо студентов MIT](https://en.wikipedia.org/wiki/Cursor_%28company%29) в 2022-м, посевной раунд в 2023-м дал фонд OpenAI. То есть OpenAI одновременно кормила Copilot моделями и финансировала того, кто его обойдёт. В августе 2025-го [CEO GitHub объявил об уходе](https://www.geekwire.com/2025/github-will-join-microsofts-coreai-group-with-departure-of-ceo-thomas-dohmke/), замену не назначили, GitHub перешёл под CoreAI Microsoft. Компания, которая семь лет жила отдельно, стала подразделением.

Теперь про парадокс. Считалось, что у кого данные, тот и выиграет, а весь код мира лежал у GitHub. Только данные оказались нужны один раз: чтобы обучить модель. Публичный код с GitHub давно собран в открытые датасеты: [The Stack v2](https://huggingface.co/datasets/bigcode/the-stack-v2-train-full-ids) это 3,3 миллиарда файлов из 104 миллионов репозиториев, на нём учили StarCoder2. Обучили все, и после этого преимущество GitHub кончилось. Хранить код и писать код это разные бизнесы. Второй делает тот, у кого модель и кто быстрее меняет форму продукта.

Есть и версия, в которой GitHub ничего не проиграл. Полтораста миллионов разработчиков по-прежнему держат код у него, пулл-реквесты агентов приходят к нему, облачный агент Copilot живёт внутри его интерфейса. Может, это его настоящая гонка: быть местом, куда любой агент приносит результат. Тогда Copilot был страховкой, чтобы место не увели, и продуктом ему быть не требовалось.

Но в опросе 39 против 21, и я помню, как начиналось. GitHub хранил весь код. Оказалось, что хранить и писать это разные ремёсла, и второе он отдал тем, у кого не было ни одного репозитория.
