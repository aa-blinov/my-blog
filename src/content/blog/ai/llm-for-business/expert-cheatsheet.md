## Контекстный пакет

```
Ситуация:     Что происходит сейчас?
Решение:      Что стоит на кону?
Контекст:     Что уже известно?
Неопределённость: Чего не знаем?
Ограничения:  Что нельзя игнорировать?
Хороший результат: В каком виде вернуть итог?
```

---

## Пять слоёв архитектуры контекста

| Слой | Что хранит |
| --- | --- |
| Входящий сигнал | Задачи, письма, сигналы — сырой поток |
| Проектное пространство | Живая работа по направлению |
| Пакет источников | Документы, файлы, данные по задаче |
| Память и журнал решений | Допущения, открытые вопросы, принятые решения |
| Архив артефактов | Завершённые результаты — записки, выводы |

---

## Семь проходов среды принятия решений

1. **Формулировка:** что именно решается, кто принимает решение, к какому сроку
2. **Поле вариантов:** 4+ реалистичных пути, включая контринтуитивные
3. **Контраргумент:** сильнейшее возражение против фаворита
4. **Предварительный разбор провала:** три сценария неудачи и ранние сигналы
5. **Сценарии:** базовый, сильный и неприятный
6. **Рекомендация:** взвешенный выбор и оставшиеся вопросы
7. **Упаковка:** записка для принятия решения на одну страницу

## Пять осей маршрутизации

| Ось | Вопрос |
| --- | --- |
| Глубина | Черновик или глубокий многопроходный анализ? |
| Источник правды | Веб / свои документы / живые подключения? |
| Срочность | Нужно сейчас или можно запустить фоном? |
| Цена ошибки | Можно с сыростью или нужен строгий контроль? |
| Тип выхода | Текст / таблица / решение / действие? |

## Рабочий верстак эксперта

| Роль | Когда использовать |
| --- | --- |
| Основной чат | Быстрый черновик, упаковка мысли |
| Глубокое исследование | Внешние источники, несколько итераций |
| Рабочее пространство по источникам | Ваши документы, интервью, файлы |
| Среда анализа | Числа, таблицы, CSV, расчёты |
| Проектное пространство | Долгая работа с устойчивым контекстом |
| Подключения | Живые системы, CRM, базы знаний |
| Длительная задача | Работа без ожидания в открытом окне |
| Автоматизация / агент | Повторяемые и полуавтономные сценарии |

## Лестница делегирования

```
1. Помощь в формулировке    → советник
2. Подготовка артефакта     → исполнитель черновика
3. Многошаговый анализ      → автономный аналитик
4. Длительное исполнение    → фоновый исполнитель
5. Повторяемый контур       → автоматизированная система
```

## Пять типичных сбоев агентного контура

| Сбой | Признак | Защита |
| --- | --- | --- |
| Тихий дрейф | Качество падает без явного сбоя | Регулярный ручной просмотр результатов |
| Избыточная уверенность | Вывод звучит убедительно без оснований | Явный шаг: «укажи допущения» |
| Перерасход полномочий | Контур делает больше, чем поручали | Явный список разрешённых действий |
| Старая память | Контур работает по устаревшим правилам | Обязательная частота пересмотра |
| Бесконтрольный шум | Артефакты копятся нетронутыми | Проверка: кто реально использует результат? |

## Ритм нативной компании

| Горизонт | Артефакты |
| --- | --- |
| Ежедневно (утро) | Пакет внимания: открытые решения, сигналы, встречи |
| Ежедневно (вечер) | Журнал сигналов: что яснее, что открыто, что сохранить |
| Еженедельно | Записка руководителя, обзор гипотез, обзор контуров |
| Ежемесячно | Обзор уроков: сильные решения, слабые, что закрыть |

---

## Роли в нативной компании

| Роль | Задача |
| --- | --- |
| Владелец направления | Контекстный пакет, записки, финальный выбор |
| Редактор артефактов | Качество записок, справок, сводок |
| Хранитель контекста | Порядок в проектах, памяти, журналах |
| Доменный проверяющий | Проверка вывода по существу там, где ставки высоки |
| Владелец контуров | Надзор за агентными и повторяемыми сценариями |
