В README [Қазақ Anki](https://github.com/aa-blinov/qazaq-anki) стояло: «No server. Your study progress, account and theme live in localStorage. Nothing is sent anywhere». Рядом в репозитории лежала папка `server/` с Express, а прогресс хранился в SQLite.

Это карточки для казахского с расписанием повторений по алгоритму SM-2: 3 996 слов от A1 до C1, у каждого казахское слово, транслитерация, русский перевод и озвучка. По PRODUCT.md проект начинался для одного конкретного ученика, и это до сих пор самое точное описание аудитории.

Расхождение есть с первого дня истории. Самый ранний коммит от 31 августа уже содержит все 3 996 карточек и сервер, а README в нём описывает прототип: 500 слов и всё в браузере. 22 сентября в README исправили число карточек. Фразу про сервер тогда же переписали так, что она зазвучала лучше и осталась ложью.

3 октября вышел коммит [«Correct 14 false claims in the README»](https://github.com/aa-blinov/qazaq-anki/commit/03e7417), и его сообщение читается как протокол. Пароли в README хэшировались bcrypt «на клиенте в 8 раундов», в коде это 10 раундов на сервере. Словарь README приписывал Wordmastery, а в каждой из 3 996 карточек стоит тег `kazcorpus-lexmin-v1`. README обещал, что `npm run deploy` собирает и публикует `dist/`, а команда публиковала лендинг и ничего не собирала. Ветки `master`, которую советовала инструкция, в репозитории не существовало.

У лжи были последствия за пределами текста. GitHub Pages раздавал собранный `dist/`, то есть приложение без API: зарегистрироваться на таком сайте было нельзя. 2 октября Pages получил статичную страницу, которая рассказывает, что это за продукт, и показывает команды запуска у себя.

На следующий день после правки README нашлась такая же история в коде. Service worker в продакшене не регистрировался: CSP `script-src 'self'` отклонял inline-скрипт с регистрацией, на живом контейнере было 0 регистраций и одно нарушение политики.

```bash
docker compose up -d --build qazaq-api qazaq-web qazaq-tts-service
```

В PRODUCT.md теперь прямо сказано, что без аккаунта приложение не работает. Сервер назван в первой же команде README, а обещание «No server» продержалось в нём больше месяца.
