Для казахского хотелось карточки с русским переводом и понятным расписанием повторений. Так появился [Қазақ Anki](https://github.com/aa-blinov/qazaq-anki): веб-приложение, которое можно запустить у себя.

Внутри 3 996 слов по уровням от A1 до C1, сгруппированных по темам. У карточки есть казахское слово, транслитерация, русский перевод и ссылка на источник. Произношение озвучено; если для слова ещё нет записи, приложение может синтезировать её при запросе.

Повторения считает алгоритм SM-2. Каждый день собирается очередь новых карточек и повторений; её размер можно изменить. Есть поиск по словам и темам, собственные карточки, статистика и импорт колоды Anki. Прогресс можно выгрузить в JSON и восстановить.

Приложение выросло из версии, которая хранила данные в браузере. Теперь у него есть сервер: учётные записи, история и прогресс лежат в SQLite на машине, где он запущен. Браузер хранит токен входа и настройки интерфейса. Одна только статическая страница без сервера больше не обеспечивает работу аккаунтов.

```bash
git clone https://github.com/aa-blinov/qazaq-anki.git
cd qazaq-anki
docker compose up -d --build qazaq-api qazaq-web qazaq-tts-service
```

После запуска открываешь `localhost:8080` и создаёшь аккаунт. React отвечает за интерфейс, Express за сервер, Piper за синтез речи. Инструкции по резервному копированию и развёртыванию есть в репозитории.
