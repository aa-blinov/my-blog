Учить язык по карточкам работает, это знают все, кто пробовал Anki. Проблема в колодах: для казахского их мало, они разрозненные, и ставить ради этого десктопный Anki с синхронизацией через чужой сервер не хотелось.

Так появился [Қазақ Anki](https://github.com/aa-blinov/qazaq-anki), веб-приложение с интервальным повторением, которое живёт на GitHub Pages и не имеет бэкенда.

Внутри 3 996 слов по пяти уровням CEFR, от A1 до C1, разложенные по темам. Источник – публичный список Wordmastery и школьный лексикон, PDF распарсены скриптом в один `decks.json`. Карточка показывает слово и транслитерацию, по пробелу переворачивается в русское значение, дальше четыре оценки: Again, Hard, Good, Easy, или клавиши 1–4.

Расписание считает SM-2, тот же алгоритм, что в классическом Anki: первый повтор через день, второй через шесть, дальше предыдущий интервал умножается на коэффициент лёгкости, который плавает от твоих ответов. Есть режим «All», чтобы прогнать весь уровень без учёта сроков, страница со всеми карточками и поиском, статистика с точностью и кольцами освоения по уровням и темам.

Сервера нет совсем. Аккаунт, прогресс и тема лежат в `localStorage`, пароль хешируется bcrypt прямо в браузере. Это удобство, не безопасность: любой с доступом к профилю браузера прочитает данные. Для карточек это нормальный компромисс, если не класть туда ничего чувствительного.

Под капотом React 19 и Vite 6, 110 килобайт в gzip, светлая и тёмная темы, клавиатура и `reduced-motion`. Деплой одной командой `npm run deploy` в ветку `gh-pages`.

Для тех, кто учит казахский и хочет карточки без установки, регистрации и облака.
