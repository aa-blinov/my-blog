Я много печатаю. Иногда проще сказать мысль, чем набирать её руками. Так появился [Lazy to Text](https://github.com/aa-blinov/lazy-to-text): нажимаешь горячую клавишу, говоришь, останавливаешь запись и получаешь текст в активном окне.

Распознавание работает на компьютере. Есть модели для русского и других языков, включая GigaAM, Whisper, Parakeet и Canary. Можно расшифровать готовый аудио- или видеофайл и отредактировать результат перед копированием. В приложении есть история с поиском и экспортом, индикатор микрофона и настройки моделей.

Теперь Lazy to Text работает на Windows, macOS и Linux. Интерфейс сделан на Electron, распознавание и работа с микрофоном выполняются отдельным процессом на Python. В текущей версии Windows и Linux используют процессор; на Apple Silicon доступен CoreML с переходом на процессор при необходимости. Прежний интерфейс на Qt и сборка с CUDA больше не актуальны.

Готовые установщики и переносимая версия для Windows лежат в [релизах](https://github.com/aa-blinov/lazy-to-text/releases/latest). Для macOS есть сборка под Apple Silicon, для Linux доступны AppImage и пакет deb. На Linux глобальным клавишам нужен X11. При первом запуске модель нужно выбрать и скачать.

Аудио остаётся на устройстве. Дополнительная обработка текста языковой моделью выключена по умолчанию; если включить облачного провайдера, ему отправится распознанный текст. Это полезно учитывать, когда диктуешь что-то личное.

Для Windows по умолчанию `Ctrl+F2` начинает запись, `Ctrl+F3` останавливает и вставляет текст. Клавиши можно изменить в настройках. Если надиктовываю задачу агенту, напоминаю ему, что распознавание могло ошибиться и непонятное слово лучше уточнить.
