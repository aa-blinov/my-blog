Эту строку я оставил в [сообщении коммита](https://github.com/aa-blinov/paratrack/commit/85164f00) 26 сентября: документ мог показать «3h 30m × 50 = 175.22». Счета, выплаты и отчёт по оплачиваемому времени считали сумму от точных секунд, а часы печатали с округлением до минуты. Часы, ставка и сумма в одном документе не сходились.

Починка заняла один коммит. Оплачиваемое время округляется до 0,01 часа, то есть до 36 секунд, и сумма считается от округлённой величины. Строки, которые округлились до 0,00 часа, из документа пропадают.

Начиналось всё без денег. 8 октября 2025 года [paratrack](https://github.com/aa-blinov/paratrack) назывался better-track и был [консольным таймером на Python](https://github.com/aa-blinov/paratrack/commit/c8d451e0): 13 файлов, 1632 строки, в README слова «minimalist» и «parallel activity tracking». Несколько таймеров одновременно живут в проекте до сих пор. 23 ноября проект получил имя ParaTrack, и после этого в истории 303 дня тишины.

Когда она кончилась, 22 сентября 2026 года, Python исчез и появился Go, а коммит называется «replace hand-rolled SVG with ECharts». [Пятьдесят файлов](https://github.com/aa-blinov/paratrack/commit/0f6a610d), плюс 4954 строки, минус 3393. Отдельного коммита про переход на Go в истории нет. Дальше события пошли быстро: 23 сентября появились пользователи и команды, 26 сентября в одном коммите волны с первой по девятую (интеграции, счета, выплаты, PWA, токены API), 27 сентября SQLite убрана и осталась только PostgreSQL. 4 октября за вечер вышло 27 коммитов вида «migrate … to React», с 20:05 до 23:32 по UTC.

Деньги задали остальное. Когда по часам платят, число перестаёт быть справкой. Сессию, вошедшую в отправленный счёт, нельзя выставить второй раз, поэтому она блокируется. Выплата, которая пересекается с прежними, показывает предупреждение: часы были бы оплачены дважды, и создать её можно только после подтверждения. Утверждённая неделя табеля закрыта для записи, и отказ называет эту неделю и говорит, кто может её открыть.

Цвет активности тоже должен что-то значить. Сначала он выводился хешем имени. 8 октября я замерил это на стенде с 14 активностями: занято 9 слотов палитры, в четырёх живут сразу несколько имён. Двадцать равномерных оттенков при протанопии дают минимальный ΔE 1,3, то есть попарно сливаются, поэтому цвет теперь хранится.

Сейчас это 642 коммита, 77 тысяч строк Go без тестов и 43 тысячи строк тестов в 364 файлах. Одна программа обслуживает веб и консоль, а данные живут только в PostgreSQL.

```bash
git clone https://github.com/aa-blinov/paratrack
cd paratrack
cp .env.example .env   # POSTGRES_PASSWORD и PARATRACK_SECRET_KEY
docker compose up -d --build
```

Дальше `localhost:8000/register`, а почту, HTTPS и бэкапы описывает [документация](https://aa-blinov.github.io/paratrack/docs/self-host/).

Секунды теряются, пока таймер только показывает. Когда по нему платят, их приходится считать.
