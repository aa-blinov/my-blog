Таймер хорошо работает, когда у тебя одна задача. У меня работа часто идёт параллельно: несколько проектов, созвоны, проверка задач. Потом нужно вспомнить, куда ушёл день, и собрать часы для клиента или команды.

Из этого вырос [paratrack](https://github.com/aa-blinov/paratrack): учёт времени, который можно развернуть на своём сервере. Несколько таймеров работают одновременно, записи можно добавить задним числом, а неделя собирается в таблицу по проектам и задачам.

Из записанного времени создаётся счёт: PDF, акт, отправка по почте и, если настроен Stripe, ссылка на оплату. Для команды есть рабочие пространства, роли, согласование недели, ставки и выплаты. Задачи можно подтягивать из GitHub, GitLab, Jira и других сервисов, а историю перенести из Toggl, Harvest или Clockify.

С телефона приложение устанавливается на главный экран. Без сети действия становятся в очередь и отправляются позже. Есть расширение для Chrome и команды для терминала.

Под капотом Go и PostgreSQL. Интерфейс собран на React; для отдельных страниц и действий остаются шаблоны Go, HTMX и Alpine.js. Файлы интерфейса входят в исполняемый файл, но для хранения данных ему нужна PostgreSQL: прежнее описание со встроенной SQLite уже устарело.

```bash
git clone https://github.com/aa-blinov/paratrack
cd paratrack
cp .env.example .env
# Заполни POSTGRES_PASSWORD и PARATRACK_SECRET_KEY.
docker compose up -d --build
```

Дальше открываешь `localhost:8000/register`. Для собственного сервера с почтой, резервными копиями и HTTPS есть [документация проекта](https://aa-blinov.github.io/paratrack/docs/self-host/).
