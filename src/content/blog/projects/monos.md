С заметками у меня всегда был один вопрос: останутся ли они моими файлами, если приложение исчезнет. Хотелось удобный поиск и связи между записями, сохранив обычную папку с Markdown.

Так появился [Monos](https://github.com/aa-blinov/monos). Заметки и вложения лежат в выбранной папке, индекс SQLite можно пересоздать. Есть [сайт](https://aa-blinov.github.io/monos/) и сборки для Windows, macOS и Linux.

Редактор поддерживает таблицы, списки задач и встраиваемые материалы. Связи между заметками работают через `[[Название заметки]]`, обратные ссылки собираются автоматически. Поиск находит текст в заголовках, тегах и содержимом, в том числе внутри слова. Последние записи можно открыть карточками или списком.

Синхронизация через Git включается по желанию: папка заметок становится репозиторием. Если одна запись изменилась на двух устройствах, приложение показывает обе версии для выбора. Есть экспорт папки в ZIP, печать в PDF и создание статического сайта.

Внизу окна можно открыть терминал в папке заметок и запустить своего агента. Изменения агента сохраняются с контрольной точкой, чтобы их можно было принять или отменить. Доступ с телефона по сети включается отдельно и по умолчанию выключен; телефонный интерфейс не получает терминал. Расширение браузера сохраняет страницу или выделенный фрагмент в Markdown.

Под капотом Electron, сервер на Node и интерфейс на Svelte. Оболочка открывает локальный сервер, а записи остаются обычными файлами.

Мне важно, что удобство приложения не привязывает заметки к его формату. Если Monos исчезнет, папку с текстом можно открыть другим редактором.
