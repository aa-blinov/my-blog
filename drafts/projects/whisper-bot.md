Голосовые сообщения удобно отправлять. Когда вокруг шумно или нужно быстро найти в записи конкретную фразу, удобнее получить текст.

Для этого я сделал [Lazy to Text bot](https://github.com/aa-blinov/lazy-to-text-bot). Ему можно переслать голосовое, видеокружок или файл с аудио и видео. Он вернёт расшифровку в тот же чат. Язык распознавания выбирается кнопкой: русский или английский.

Русскую речь распознаёт GigaAM v3 через ONNX на процессоре. Модель сама расставляет пунктуацию; отдельный облачный запрос для этого не нужен. Аудио читается потоком, а законченная расшифровка и сведения о запросе сохраняются в PostgreSQL.

Пока задача обрабатывается, бот продолжает отвечать. Сообщение попадает в очередь Redis, распознавание выполняет отдельный рабочий процесс. Администратор управляет доступом и может посмотреть статистику.

```bash
git clone https://github.com/aa-blinov/lazy-to-text-bot.git
cd lazy-to-text-bot
cp .env.example .env
# Укажи токен Telegram и идентификатор администратора.
docker compose up --build
```

Запускаются четыре контейнера: бот, рабочий процесс, Redis и PostgreSQL. При первом старте скачиваются модели. Это самостоятельный сервер; сообщения проходят через Telegram, а распознавание выполняется на твоей машине.
