[Codex Router](https://github.com/aa-blinov/codex-router) помогает переключаться между OpenAI, DeepSeek и MiniMax в Codex через один настроенный адрес провайдера.

Локальный мост получает запрос, определяет по выбранной модели, куда его отправить, и возвращает ответ. Настройки подключений и ключи находятся на машине, где он запущен. Проект рассчитан на ситуацию, когда хочется пользоваться несколькими провайдерами из одного интерфейса, не перенастраивая его каждый раз.

Установка и настройка отличаются для Windows и Linux с macOS; команды и доступные модели перечислены в [репозитории](https://github.com/aa-blinov/codex-router).
