Есть два похожих вопроса: найти ответ в папке своих документов и проверить ответ по страницам интернета. Для них у меня есть два отдельных проекта.

[simple-rag](https://github.com/aa-blinov/simple-rag) индексирует PDF и документы Word, хранит поисковый индекс на своём диске и отвечает по найденным фрагментам. Рядом с ответом показывает файл-источник. Работать можно в браузере или терминале; языковую модель подключают отдельно через совместимый интерфейс. По умолчанию используется локальный LM Studio. Если выбрать облачную модель, вопрос и найденные фрагменты будут отправлены её провайдеру.

[self-hosted-search-agent](https://github.com/aa-blinov/self-hosted-search-agent) ищет страницы в интернете, читает их и собирает ответ с опорой на источники. Он работает через поисковую службу и выбранную модель, поэтому запросы и страницы могут передаваться соответствующим провайдерам. Результат и источники всё равно стоит проверять.

Оба проекта можно запустить у себя. Инструкции по установке и ограничения находятся в их репозиториях.
