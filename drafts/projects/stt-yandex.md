У меня накапливались записи созвонов, с которыми нужно работать: найти договорённости, восстановить контекст, передать кому-то кто не был на звонке. Слушать запись заново дорого. Нужна расшифровка.

Lazy to Text помогает с диктовкой в активное окно и тоже умеет расшифровывать готовые файлы. А здесь задача другая: взять готовый аудиофайл, иногда длинный, и получить транскрипт с пониманием, кто что говорил.

Яндекс SpeechKit умеет возвращать текст с метками говорящих. Вызывать API руками неудобно: загрузи файл в Object Storage, отправь задачу, жди, забери результат, разбери NDJSON. Шагов много, каждый раз одно и то же.

Так появился [stt-yandex](https://github.com/aa-blinov/stt-yandex).

Даёшь ему аудиофайл, он делает остальное. Конвертирует многоканальную запись в моно, загружает в Yandex Object Storage, отправляет асинхронную задачу на распознавание, ждёт результата, разбирает ответ и отдаёт нормальный текст с метками спикеров.

```bash
uv run stt-cli transcribe meeting.mp3
```

На выходе два файла в папке `outputs/`: `.srt` с таймкодами и `.json` с сырыми данными. В расшифровке сразу видно кто говорил:

```
Спикер 1: Давайте начнём с результатов прошлой недели.

Спикер 2: Да, мы закрыли три задачи из пяти запланированных.
```

Сервис возвращает метки говорящих в `channelTag`, а инструмент переносит их в расшифровку. Поскольку перед отправкой запись сводится в моно, речь здесь не о сохранении отдельных стереоканалов. Метки стоит проверить по записи.

Есть один нюанс, который не очевиден: перед загрузкой инструмент проверяет, нет ли уже файла с таким именем в бакете, и прерывается если есть. Простая защита от случайного перезатирания, но я был рад, что она там есть.

Из интересного в устройстве: SpeechKit v3 возвращает результат потоком строк: каждая строка отдельный JSON, единого объекта нет. При этом одни и те же фрагменты могут прийти дважды: сначала сырой вариант, потом нормализованный с заглавными буквами и пунктуацией. Код разбирает это аккуратно: приоритет у версии с нормализацией, дубли отфильтровываются по времени и спикеру.

Для локальной диктовки и готовых записей есть Lazy to Text. stt-yandex использует облачный SpeechKit и сохраняет субтитры с метками говорящих.
