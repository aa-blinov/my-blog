Когда несколько проектов растут одновременно, хочется повторно использовать проверенные настройки и навыки.

[golden-repo](https://github.com/aa-blinov/golden-repo) описывает общий порядок файлов и README для моих репозиториев и содержит инструменты для проверки этого порядка.

[ponytail-minimax](https://github.com/aa-blinov/ponytail-minimax) переносит набор навыков Ponytail в MiniMax Code. [impeccable-mcode](https://github.com/aa-blinov/impeccable-mcode) добавляет поддержку MiniMax Code к навыку работы с интерфейсами Impeccable. Оба проекта опираются на существующие инструменты; исходники и инструкции приведены в репозиториях.
